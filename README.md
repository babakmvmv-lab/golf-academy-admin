# admin.puttclub.ir — پنل مدیریت

آینهٔ کامل سایت عمومی (شامل پنل مدیریت در `/admin/site/`) روی زیردامنهٔ اختصاصی مدیریت.
ریشهٔ زیردامنه به `/admin/site/` هدایت می‌شود. داده‌ها از همان ابر مشترک (Supabase) می‌آیند و
تمام فراخوانی‌های `/api/*` در خود مرورگر به Supabase ترجمه می‌شوند؛ مستقل از دامنه.

- گردش‌کار «Mirror site from main repo» هر روز (و به‌صورت دستی) آینه را به‌روز می‌کند.
- DNS: رکورد CNAME با نام `admin` و مقصد `babakmvmv-lab.github.io` (مدیریت در deSEC).
