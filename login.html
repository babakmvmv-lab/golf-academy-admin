ورود مدیران

فقط حساب‌هایی که در Supabase Auth مجوز web_admin یا web_shop_staff دارند وارد می‌شوند. رمز این صفحه، رمز همان حساب Supabase است — نه رمز پنل اعضا و نه رمز دمو.

Caps Lock روشن است.

رمزم را نمی‌دانم / کار نمی‌کند — چیکار کنم؟
۱. حساب درست است (admin@puttclub.ir، تأییدشده، با مجوز web_admin)؛ چیزی که این‌جا لازم است رمزِ همان رکورد در Supabase Auth است.
۲. رمز تازه: داشبورد Supabase → پروژه → Authentication → Users → کاربر admin@puttclub.ir → Update user → یک رمز جدید (دست‌کم ۱۲ نویسه) → ذخیره.
۳. بعد از آن همین‌جا وارد شو. اگر «Too many requests» دیدی، چند دقیقه (یا تا یک ساعت) صبر کن — Supabase بعد از چند تلاش اشتباه، ورود را موقتاً قفل می‌کند.
۴. «درخواست لینک بازیابی رمز» فقط کار می‌کند که SMTP روی پروژه تنظیم باشد؛ با SMTP آزمایشی سوپابیس ایمیل به این نشانی نمی‌رسد — در آن حالت همان مرحلهٔ ۲ را انجام بده.
